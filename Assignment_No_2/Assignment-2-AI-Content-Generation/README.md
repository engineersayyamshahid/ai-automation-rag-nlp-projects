## 📌 Assignment Overview

**Assignment 2: AI Content Generation**

### Objective

The objective of this assignment is to use **Generative AI tools** to create different types of digital content from **one common idea**.

For this assignment, I selected **SYFA Digital**, a modern software and digital solutions agency, as the central topic.

The campaign focuses on:

> **"Transforming Ideas into Digital Success."**

Using Generative AI, I created four different types of content around the same campaign:

1. 📝 Written Content
2. 🖼️ AI-Generated Promotional Poster
3. 📊 Presentation
4. 🎬 AI-Generated Promotional Video

The purpose was to demonstrate how a single business idea can be transformed into multiple digital content formats using AI.

# 🎯 Assignment Requirements

The official assignment requires students to:

### 1. Written Content

Create a social media post or short promotional article using Generative AI.

### 2. Image

Generate one relevant AI image or promotional poster.

### 3. Presentation

Create a presentation of approximately **5 slides**.

### 4. Video
