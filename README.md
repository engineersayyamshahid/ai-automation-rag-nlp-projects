# 🧠 Core Concepts

## 1. Prompt Engineering

**Prompt Engineering** is the process of designing effective instructions for AI models.

Instead of simply asking:

```text
Tell me about Python.
```

we can provide a structured instruction:

```text
Explain Python to a beginner.

Requirements:
1. Use simple English.
2. Give a real-world example.
3. Explain the concept step by step.
4. Provide a small Python example.
5. Give 3 practice questions.
```

### Why it matters

A good prompt can improve:

* Accuracy
* Relevance
* Consistency
* Output structure
* Reasoning
* Task completion

### Example

```text
Role:
You are an AI programming teacher.

Task:
Explain APIs to a beginner.

Requirements:
- Use simple English.
- Use a real-world example.
- Explain request and response.
- Provide a Python example.
```

# 📚 5. Retrieval-Augmented Generation (RAG)

## What is RAG?

**RAG = Retrieval-Augmented Generation**

RAG allows an AI model to retrieve relevant information from external data before generating an answer.

Instead of relying only on the knowledge stored inside the AI model:

```text
User Question
      ↓
Retrieve relevant information
      ↓
AI Model
      ↓
Answer
```

---

## 🧠 Simple RAG Example

Imagine we have a university PDF containing:

```text
University Rules
Attendance must be above 75%.
```

User asks:

```text
What is the minimum attendance requirement?
```

A RAG system can:

```text
Question
   ↓
Convert question to embedding
   ↓
Search documents
   ↓
Find relevant information
   ↓
Send context to LLM
   ↓
Generate answer
```

Answer:

```text
The minimum attendance requirement is 75%.
```

# 🔍 6. RAG Models

A typical RAG architecture contains several components.

```text
                 ┌──────────────┐
                 │   Documents  │
                 └──────┬───────┘
                        ↓
                 Document Chunking
                        ↓
                    Embeddings
                        ↓
                 Vector Database
                        ↓
User Question → Retrieval/Search
                        ↓
                  Relevant Context
                        ↓
                       LLM
                        ↓
                  Final Response
```

### Main components

### 1. Documents

Information sources such as:

* PDF
* TXT
* DOCX
* Websites
* Databases
* Knowledge bases

### 2. Chunking

Large documents are divided into smaller pieces.

```text
Large Document
      ↓
Chunk 1
Chunk 2
Chunk 3
Chunk 4
```

### 3. Embeddings

Text is converted into numerical vectors that represent semantic meaning.

Example:

```text
"Python programming"
        ↓
[0.12, 0.84, 0.31, ...]
```

### 4. Vector Database

Embeddings are stored so that similar information can be retrieved efficiently.

### 5. Retrieval

When the user asks a question, the system searches for the most relevant chunks.

### 6. Generation

The retrieved context is given to an LLM.

The LLM generates the final response using the provided information.

# 🔢 10. Embeddings

An embedding converts information such as text into a numerical representation.

For example:

```text
"Machine Learning"
        ↓
[0.21, 0.83, 0.42, 0.17, ...]
```

Texts with similar meanings generally have vectors that are closer in embedding space.

### Example

```text
"How can I learn Python?"
```

and

```text
"What is the best way to study Python?"
```

may have similar embeddings because they have similar meanings.

Embeddings are heavily used in:

* RAG
* Semantic Search
* Recommendation Systems
* Document Search
* Question Answering
* Knowledge Bases
